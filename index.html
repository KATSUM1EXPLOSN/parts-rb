Публикация на GitHub Pages

Как запустить мини-сайт за 1 минуту:

  1. Создайте репозиторий на GitHub, например parts-rb.
  2. Загрузите этот файл и переименуйте его в index.html.
  3. В репозитории перейдите в Settings → Pages.
  4. В разделе Branch выберите main и нажмите Save.
  5. Через 30 секунд сайт доступен по адресу:
    https://your-name.github.io/parts-rb
💡 В Telegram: Откройте @BotFather, создайте Mini App через команду /newapp и вставьте ссылку вашего GitHub Pages!
